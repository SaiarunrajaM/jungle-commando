HOSTING THIS GAME

This is still a single static file — one index.html with all CSS, JavaScript and audio synthesis inlined, no build step and no backend. That means any static host works. Save the page's source as index.html, then pick a deployment below.

GitHub Pages free

  1. Create a repo, e.g. jungle-commando, and add your index.html to it.
  2. Commit & push: git add index.html && git commit -m "add game" && git push
  3. On GitHub: Settings → Pages → Source, pick the main branch and / (root).
  4. Save — your game goes live at <user>.github.io/jungle-commando in about a minute.

Netlify Drop no account*

  1. Put index.html in its own folder.
  2. Go to app.netlify.com/drop and drag the folder onto the page.
  3. Netlify uploads it and hands you a live *.netlify.app URL instantly.
  4. Optional: create a free account to keep the site and set a custom subdomain.

Vercel CLI

  1. Install the CLI: npm i -g vercel
  2. From the folder containing index.html, run vercel.
  3. Accept the defaults (no framework/build step needed for a static file).
  4. Run vercel --prod to promote it to your production URL.

itch.io game audience

  1. Zip the folder containing index.html (it must be at the zip's root).
  2. On itch.io: Upload New Project, kind = HTML, upload the zip.
  3. Check "This file will be played in the browser" and set the embed size to 960×540 (or larger).
  4. Publish — itch.io is a dedicated audience for browser games and handles the player embed for you.

Testing locally first: any static server works, e.g. npx serve . or python3 -m http.server from the folder, then open localhost in a browser. Note: mobile browsers require a tap before audio starts (browser autoplay policy) — the PRESS START button handles that.

Built with HTML Canvas & Web Audio — keyboard or on-screen controls, no plugins required.
